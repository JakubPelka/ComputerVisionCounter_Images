# Release notes - v0.2.0 candidate

This release is intended as the first cleaned baseline release of ComputerVision Counter Images.

## Included

- Desktop image-counting workflow using YOLO `.pt` models.
- Class selection.
- Optional AOI-based counting.
- Annotated image output.
- CSV/JSON exports.
- GIS-friendly export path where supported.
- Repository cleanup: MIT license, clearer README, expanded `.gitignore`, documentation and release notes.

## Not included

- Detection models.
- Private test images.
- Generated outputs.
- Local package folders.
- ONNX or ONNX Runtime packages in the default .venv setup.
- ONNX as a stable supported workflow.
- Segmentation model support.
- Segmentation-specific dependencies.

## Release status

This is a cleanup release candidate. Run manual smoke testing before publishing the GitHub release.
